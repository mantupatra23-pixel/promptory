# promptory

The official CLI for Promptory.xyz — production-grade AI prompt engineering workflows.

## Instant Usage

Pull verified AI system prompts directly into your project as .cursorrules:

npx promptory add fastapi-code-review --cursor

Pull as a standalone markdown file:

npx promptory add founder-performance --raw

## Options

- --cursor: Generates .cursorrules in your project root.
- --raw: Generates <slug>.md markdown prompt file.
